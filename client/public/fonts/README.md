# Local UI fonts

The clinic uses its existing DM Sans and Manrope families from local Latin variable WOFF2 assets, so rendering does not require a remote font stylesheet.

- DM Sans: `@fontsource-variable/dm-sans` 5.3.0, `dm-sans-latin-wght-normal.woff2`; project authors: https://github.com/googlefonts/dm-fonts
- Manrope: `@fontsource-variable/manrope` 5.3.0, `manrope-latin-wght-normal.woff2`; project authors: https://github.com/sharanda/manrope

Both are distributed under the SIL Open Font License 1.1. The complete copyright notices and licenses are included alongside each font.
